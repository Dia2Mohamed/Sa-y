# سَعْي | SA'Y

A calm, bilingual personal growth dashboard focused on intention, daily tasks, habits, reflection, and learning.

## Features
- Arabic and English interface with RTL/LTR switching
- Daily task list and habit check-ins
- Monthly goal and reflection notes
- Learning resource links
- Local browser storage (no account or server required)
- Installable PWA with basic offline caching

## Publish free with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment and open the URL shown there.

## Data and privacy
Tasks, habits, goals, and reflections are stored in this browser using localStorage. They are not synced across devices and may be lost if browser site data is cleared. Google Fonts needs an internet connection; the core app files are cached for offline use after the first successful load.
